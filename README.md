SmartBook AI – Book Recommendation System

About the Project

SmartBook AI is a Python-based, rule-based book recommendation chatbot that suggests books based on the user's reading preferences.

Features

- Interactive chatbot interface using Python Tkinter
- Personalized greeting using the user's name
- Book recommendations based on user preferences
- Genre selection
- Language preference, including Marathi and English books
- Book length and reading-level preferences
- Mood-based recommendations
- Weighted scoring algorithm for ranking books
- Restart and recommend-again functionality

Technologies Used

- Python
- Tkinter
- Rule-Based Artificial Intelligence
- Weighted Scoring Algorithm

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python smartbook.py
